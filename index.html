    How this works
    • A mock WebSocket pushes new listings every few seconds, with automatic reconnect when the network returns.
    • New jobs queue behind a "Show new jobs" button so the list never jumps while you read.
    • Save is optimistic: the star updates instantly and rolls back if the request fails. Offline saves are queued and synced later.
    • Open any job in an accessible dialog (focus is trapped, then returned), apply with the same optimistic pattern, and track applications with the Applied filter.
    • The feed, saved jobs, applications and queued actions are cached in IndexedDB, so the app opens with content offline.
    • Accessibility: semantic HTML, skip link, visible focus, aria-pressed controls, a polite live region for new jobs, reduced-motion support.

    All listings are generated demo data.
